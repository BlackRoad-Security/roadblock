Security that works while you sleep

Automated defense that requires zero daily attention.

🛡

CrowdSec IDS

Community-driven intrusion detection. Behavioral analysis catches novel attacks. Shared threat intelligence from thousands of nodes worldwide. Automatic ban decisions with configurable thresholds.

🔐

Certificate Management

Automatic TLS certificate provisioning and renewal via Let's Encrypt. Certificate transparency monitoring. Revocation alerts. Support for wildcard certificates across all 20 root domains.

📊

Audit Logging

Every connection, authentication attempt, and configuration change is logged to an append-only SQLite database. FTS5 search across all events. Export to SIEM-compatible formats for compliance.

🔥

Firewall Rules Engine

Declarative firewall configuration. Rules versioned in git. Automatic rollback on lockout detection. Separate rulesets per node with fleet-wide policy inheritance.

🌐

DNS Security

PowerDNS with DNSSEC signing. Pi-hole for recursive filtering. DNS-over-HTTPS support. Prevents DNS cache poisoning, tunneling, and rebinding attacks. All queries audited.

👀

Network Monitoring

Real-time traffic analysis across all WireGuard peers. Anomaly detection for unusual data volumes. Connection tracking per service. Bandwidth graphs with historical comparison.

# Roadblock — Zero-Trust Security Configuration
layers:
  edge:
    provider: caddy
    tls: auto                    # Let's Encrypt
    min_tls: "1.3"
    rate_limit: 100/min
    domains: 151

  mesh:
    provider: wireguard
    topology: full-mesh
    peers: 12
    keepalive: 25s
    allowed_ips: 10.0.0.0/24

  dns:
    provider: pi-hole
    blocklists: 120+ domains
    dnssec: enabled
    upstream: powerdns (self-hosted)

  auth:
    method: ed25519
    session_ttl: 1h
    rotation: automatic
    audit: sqlite + fts5

ids:
  engine: crowdsec
  scenarios: [ssh-bf, http-probing, dns-tunneling]
  ban_duration: 24h
  community_blocklists: enabled

Deploy in 5 minutes

# Install Roadblock
curl -fsSL https://blackroad.io/install/roadblock | bash

# Initialize security profile
roadblock init --profile zero-trust

# Configure defense layers
roadblock layer add edge    --provider caddy
roadblock layer add mesh    --provider wireguard
roadblock layer add dns     --provider pihole
roadblock layer add auth    --provider ed25519

# Enable CrowdSec IDS
roadblock ids enable --engine crowdsec

# Run security audit
roadblock audit --full
